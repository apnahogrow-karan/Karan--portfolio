## Publish free with GitHub Pages
1. Sign in to [GitHub](https://github.com/) and create a **New repository**.
2. Name it `karan-portfolio` (or any name). For a public website, set visibility to **Public**.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `assets` folder. Keep the folder structure unchanged.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show your public website URL in the Pages section. If the repository is named `karan-portfolio`, the URL will usually be `https://YOUR-USERNAME.github.io/karan-portfolio/`.
